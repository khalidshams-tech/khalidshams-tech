# Portfolio Automation

This folder contains a monthly GitHub portfolio review automation.

## What It Does

The automation runs once per month with GitHub Actions. It reviews public repositories for the `khalidshams-tech` account and creates a pull request with suggested portfolio updates.

It can help with:

- GitHub profile README suggestions
- Project README improvement notes
- blogIT138 website content suggestions
- LinkedIn-friendly project descriptions
- Monthly GitHub progress summary
- Codex project notes, if you paste them into `codex_monthly_summary.md`

## What It Does Not Do

- It does not delete files
- It does not push directly to `main`
- It does not directly edit `blogIT138`; it creates reviewed website suggestions first
- It does not publish sensitive information on purpose
- It does not invent screenshots
- It does not automatically archive repositories

Some files are generated by the workflow after it runs.

## Setup Instructions

1. Open the repository on GitHub.
2. Go to **Actions**.
3. Enable workflows if GitHub asks.
4. The workflow runs automatically on the first day of each month.
5. To test it manually, open **Actions > Monthly Portfolio Review > Run workflow**.
6. Review the pull request created by the automation.
7. Edit or approve the suggestions before merging.

## Monthly Manual Step

Before the monthly workflow runs, update:

```text
automation/codex_monthly_summary.md
```

Paste notes about:

- New Codex chats or tasks
- Generated code that became useful
- Completed labs
- New AWS screenshots
- New certificates
- New LinkedIn updates
- New projects you want to feature

## Security Rules

Before adding screenshots or copied notes, remove:

- AWS account IDs
- Public IP addresses
- Access keys or secret keys
- `.pem` private keys
- Passwords
- School lab credentials
- Personal information that should not be public
